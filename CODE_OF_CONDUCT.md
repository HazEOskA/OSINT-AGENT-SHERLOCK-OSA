# Code of Conduct

We follow the Contributor Covenant 2.1 principles: be respectful, critique work
rather than people, protect private information, and reject harassment.

Security research contributions must target systems that the contributor owns
or is explicitly authorised to test. Instructions or code whose primary purpose
is unauthorised access will not be accepted.

Report conduct concerns privately to the repository owner. Report
vulnerabilities through the process in `SECURITY.md`.
