# Pivot correlation

Łącz findings wyłącznie po jawnych, reprodukowalnych kluczach. Rozdziel `LIVE_SOURCE_CONFIRMED`, `SOURCE_REPORTED`, `CANDIDATE_REQUIRES_CORRELATION` i `INDEX_MATCH_NOT_CONTENT_VERIFIED`.

Nie podnoś confidence na podstawie samego podobieństwa nazwy lub username.
