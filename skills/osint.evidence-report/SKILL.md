# Evidence report

Zapisz status każdego adaptera, liczbę findings, SHA-256 wyniku i append-only hash-chain. W publicznym preview ledger jest per request i zawiera maskę oraz hash zapytania, nigdy surowy identyfikator.

Raport musi jawnie wskazać, czy użyto sieci, LLM, Tor, prywatnego workera i czy zwrócono surowe rekordy.
